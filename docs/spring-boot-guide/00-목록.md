# Spring Boot 가이드 — 목록

이 폴더는 Spring Boot를 **목록 → 설명 → 예제** 순서로 학습하기 위한 문서입니다.

## 기준 스택

| 항목 | 값 |
|------|-----|
| Java | 21 |
| Spring Boot | 3.5.x (Jakarta EE, Java 21) |
| 빌드 | Gradle (`build.gradle`) |
| 웹 | `spring-boot-starter-web` |
| 단순 조회·등록·수정·삭제 | Spring Data JPA + **QueryDSL** |
| 조인·동적 SQL 등 복잡한 쿼리 | **MyBatis** |
| DB | Oracle (`ojdbc11`) |
| 포트 | `8080` |

**역할 분담 한 줄**

- 한 테이블(또는 단순 조건)의 SELECT / INSERT / UPDATE / DELETE → JPA · QueryDSL
- 여러 테이블 JOIN, 화면용 플랫 조회, 동적 WHERE가 긴 SQL → MyBatis XML

## JPA vs MyBatis 사용 목록

| 구분 | 도구 | 이 화면에서 해당하는 일 |
|------|------|--------------------------|
| 단건 조회 | JPA `findById` | 권한 행 1건 조회 |
| 단순 목록 | QueryDSL | 부서명 일치, 사용여부 = Y |
| 등록 | JPA `save` | 세부권한 1행 INSERT |
| 수정 | JPA `save` / 변경 감지 | 사용여부 변경 |
| 삭제 | JPA `delete` | 세부권한 1행 DELETE |
| 복잡한 조회 | MyBatis | B002 그리드: t1 JOIN t2 플랫 목록 |
| 복잡한 옵션 | MyBatis | DISTINCT 부서, 모달용 DETAIL_LIST |
| 동적 검색 | MyBatis | 필터가 많거나 Oracle 함수가 필요한 조회 |

## 이 프로젝트 API 목록

### B001 그리드

| Method | URL | 데이터 접근 |
|--------|-----|-------------|
| GET | `/api/grid/options/departments?week=` | QueryDSL 또는 목 데이터 |
| GET | `/api/grid/options/sections?week=&departmentCode=` | QueryDSL 또는 목 데이터 |
| GET | `/api/grid/options/categories` | JPA `findAll` |
| GET | `/api/grid/options/statuses` | JPA `findAll` |
| GET | `/api/grid/options/types` | JPA `findAll` |
| GET | `/api/grid/search` | 필터가 많으면 MyBatis |

### B002 세부권한

| Method | URL | 데이터 접근 |
|--------|-----|-------------|
| GET | `/api/b002/search` | **MyBatis** (t1 JOIN t2) |
| GET | `/api/b002/options/departments` | MyBatis DISTINCT 또는 QueryDSL |
| GET | `/api/b002/options/detail-auths` | QueryDSL / MyBatis |
| GET | `/api/b002/options/detail-list` | JPA `findAll` (단건 테이블) |
| POST | `/api/b002/details/sync` | **JPA** INSERT/DELETE + `@Transactional` |
