# Spring Boot 가이드 — 목록

이 폴더는 Spring Boot를 **목록 → 설명 → 예제** 순서로 학습하기 위한 문서입니다.  
기준 환경은 이 프로젝트(`react_beginner`)의 백엔드입니다.

| 항목 | 값 |
|------|-----|
| Spring Boot | 2.7.18 |
| Java | 1.8 (JDK 8) |
| 빌드 | Maven Wrapper (`mvnw` / `mvnw.cmd`) |
| 웹 | `spring-boot-starter-web` |
| DB | `spring-boot-starter-jdbc` + Oracle (`ojdbc8`) |
| 포트 | `8080` |

## 학습 주제 목록

| 번호 | 주제 | 한 줄 요약 | 이 프로젝트에서 볼 곳 |
|------|------|------------|------------------------|
| 1 | Spring Boot란? | 설정과 실행을 단순화한 Spring 기반 웹 프레임워크 | `backend/pom.xml` |
| 2 | 프로젝트 구조 | 패키지와 계층(Controller / Service / Repository / DTO) | `backend/src/main/java/...` |
| 3 | Maven과 Starter | 의존성을 한 묶음으로 가져오는 방식 | `backend/pom.xml` |
| 4 | 애플리케이션 진입점 | `@SpringBootApplication`과 `main` | `ReactBeginnerApplication.java` |
| 5 | 설정과 프로파일 | `application.properties`, `local` 프로파일 | `src/main/resources/` |
| 6 | 의존성 주입 (DI) | 생성자로 빈을 주입받는 방식 | Controller, Service, Repository |
| 7 | REST Controller | URL을 메서드에 연결하는 계층 | `GridController`, `B002Controller` |
| 8 | 요청 파라미터 | `@RequestParam`, `@RequestBody` | GET 조회 / POST 동기화 |
| 9 | 응답 JSON | `Map` / DTO가 JSON으로 변환되는 원리 | `success`, `data`, `totalCount` |
| 10 | Service | 업무 로직을 모으는 계층 | `GridMockService`, `B002AuthService` |
| 11 | DTO | 화면·API로 주고받는 데이터 상자 | `dto` 패키지 |
| 12 | Repository와 JdbcTemplate | SQL로 DB를 조회·변경 | `B002AuthRepository` |
| 13 | 트랜잭션 | 여러 SQL을 한 단위로 묶기 | `@Transactional` |
| 14 | CORS | React(5173)에서 API(8080)를 호출하려면 필요 | `WebConfig` |
| 15 | 실행과 요청 흐름 | 앱을 띄우고 요청이 계층을 타고 가는 경로 | `mvnw spring-boot:run` |

## 이 프로젝트 API 목록

### B001 그리드 (목 데이터)

| Method | URL | 설명 |
|--------|-----|------|
| GET | `/api/grid/options/departments?week=` | 부서 옵션 |
| GET | `/api/grid/options/sections?week=&departmentCode=` | 팀 옵션 (전체 포함) |
| GET | `/api/grid/options/categories` | 카테고리 다중선택 옵션 |
| GET | `/api/grid/options/statuses` | 상태 라디오 옵션 |
| GET | `/api/grid/options/types` | 유형 체크박스 옵션 |
| GET | `/api/grid/search` | 그리드 목록 조회 |

### B002 세부권한 (Oracle)

| Method | URL | 설명 |
|--------|-----|------|
| GET | `/api/b002/search` | 권한 그리드 조회 |
| GET | `/api/b002/options/departments` | 부서 옵션 |
| GET | `/api/b002/options/detail-auths` | 세부권한 옵션 |
| GET | `/api/b002/options/detail-list` | 세부권한 선택 모달 목록 |
| POST | `/api/b002/details/sync` | 팝업 확인 시 세부권한 INSERT/DELETE |

## 계층별 파일 목록

```
backend/
├── pom.xml
├── mvnw.cmd                          # Windows Maven Wrapper
├── src/main/java/com/company/reactbeginner/
│   ├── ReactBeginnerApplication.java # 진입점
│   ├── config/WebConfig.java         # CORS
│   ├── controller/
│   │   ├── GridController.java       # B001 REST
│   │   └── B002Controller.java       # B002 REST
│   ├── service/
│   │   ├── GridMockService.java      # B001 목 데이터
│   │   └── B002AuthService.java      # B002 업무 로직
│   ├── repository/
│   │   └── B002AuthRepository.java   # JDBC SQL
│   └── dto/                          # 요청·응답 객체
└── src/main/resources/
    ├── application.properties
    └── application-local.properties.example
```
