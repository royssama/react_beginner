도메인은 이 프로젝트의 B002(권한)를 사용합니다.

## 5. Entity (JPA)

단순 CRUD와 QueryDSL의 기준이 되는 테이블 매핑입니다.

```java
package com.company.reactbeginner.domain;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.SequenceGenerator;
import jakarta.persistence.Table;

@Entity
@Table(name = "TB_B002_AUTH_EXCEL_DETAIL")
public class AuthExcelDetail {

    @Id
    @Column(name = "DETAIL_ID")
    private String detailId;

    @Column(name = "DETAIL_NM")
    private String detailNm;

    @Column(name = "DETAIL_AUTH")
    private String detailAuth;

    @Column(name = "DETAIL_USE_YN")
    private String detailUseYn;

    protected AuthExcelDetail() {
    }

    public AuthExcelDetail(String detailId, String detailNm, String detailAuth, String detailUseYn) {
        this.detailId = detailId;
        this.detailNm = detailNm;
        this.detailAuth = detailAuth;
        this.detailUseYn = detailUseYn;
    }

    public void changeUseYn(String detailUseYn) {
        this.detailUseYn = detailUseYn;
    }

    public String getDetailId() { return detailId; }
    public String getDetailNm() { return detailNm; }
    public String getDetailAuth() { return detailAuth; }
    public String getDetailUseYn() { return detailUseYn; }
}
```

Boot 3이므로 import는 `javax.persistence`가 아니라 **`jakarta.persistence`** 입니다.

시퀀스 PK 예 (마스터 테이블):

```java
@Id
@GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "authExcelSeq")
@SequenceGenerator(name = "authExcelSeq", sequenceName = "SEQ_B002_AUTH_EXCEL", allocationSize = 1)
@Column(name = "AUTH_SEQ")
private Long authSeq;
```

## 6. JPA — 단순 조회 · 등록 · 수정 · 삭제

```java
package com.company.reactbeginner.repository.jpa;

import com.company.reactbeginner.domain.AuthExcelDetail;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.List;
import java.util.Optional;

public interface AuthExcelDetailRepository extends JpaRepository<AuthExcelDetail, String> {

    List<AuthExcelDetail> findByDetailId(String detailId);

    Optional<AuthExcelDetail> findByDetailIdAndDetailAuth(String detailId, String detailAuth);

    void deleteByDetailIdAndDetailAuth(String detailId, String detailAuth);
}
```

Service에서 쓰는 CRUD:

```java
// 조회
Optional<AuthExcelDetail> row =
        detailRepository.findByDetailIdAndDetailAuth(detailId, detailAuth);

List<AuthExcelDetail> list = detailRepository.findByDetailId(detailId);

// 등록 (INSERT)
detailRepository.save(new AuthExcelDetail(detailId, detailNm, detailAuth, "Y"));

// 수정 (변경 감지 — 트랜잭션 안에서)
AuthExcelDetail found = detailRepository.findById(detailId).orElseThrow();
found.changeUseYn("N");

// 삭제
detailRepository.deleteByDetailIdAndDetailAuth(detailId, detailAuth);
```

`save`는 PK가 이미 있으면 UPDATE, 없으면 INSERT로 동작합니다.  
복합 키가 아니면 새 행은 위처럼 새 Entity를 `save`하면 됩니다.

## 8. QueryDSL — 단순 조건 검색

부서가 있을 때만 WHERE를 붙이는 동적 조회입니다. JOIN이 없으면 QueryDSL이 적합합니다.

```java
package com.company.reactbeginner.repository.jpa;

import com.company.reactbeginner.domain.AuthExcel;
import com.company.reactbeginner.domain.QAuthExcel;
import com.querydsl.core.types.dsl.BooleanExpression;
import com.querydsl.jpa.impl.JPAQueryFactory;
import org.springframework.stereotype.Repository;

import java.util.List;

@Repository
public class AuthExcelQueryRepository {

    private final JPAQueryFactory queryFactory;

    public AuthExcelQueryRepository(JPAQueryFactory queryFactory) {
        this.queryFactory = queryFactory;
    }

    public List<AuthExcel> search(String deptName, String useYn) {
        QAuthExcel auth = QAuthExcel.authExcel;

        return queryFactory
                .selectFrom(auth)
                .where(
                        eqDept(auth, deptName),
                        eqUseYn(auth, useYn)
                )
                .orderBy(auth.empNo.asc(), auth.authName.asc())
                .fetch();
    }

    public List<String> findDistinctDepartments() {
        QAuthExcel auth = QAuthExcel.authExcel;
        return queryFactory
                .select(auth.deptName)
                .distinct()
                .from(auth)
                .orderBy(auth.deptName.asc())
                .fetch();
    }

    private BooleanExpression eqDept(QAuthExcel auth, String deptName) {
        if (deptName == null || deptName.isBlank()) {
            return null; // where 조건에서 무시
        }
        return auth.deptName.eq(deptName.trim());
    }

    private BooleanExpression eqUseYn(QAuthExcel auth, String useYn) {
        if (useYn == null || useYn.isBlank()) {
            return null;
        }
        return auth.useYn.eq(useYn);
    }
}
```

`QAuthExcel`은 Entity `AuthExcel`을 컴파일해야 생깁니다.  
IDE가 Q클래스를 못 찾으면 Generated Sources 폴더를 소스 루트로 지정합니다.

Java 21의 `isBlank()`로 빈 문자열을 걸러 냅니다.

## 9. MyBatis — 복잡한 JOIN 조회

그리드처럼 t1 + t2를 붙여 플랫 DTO로 받을 때는 XML이 읽기 쉽습니다.

### 9-1. Mapper 인터페이스

```java
package com.company.reactbeginner.repository.mybatis;

import com.company.reactbeginner.dto.B002AuthExcelDto;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;

import java.util.List;

@Mapper
public interface B002AuthMapper {

    List<B002AuthExcelDto> findAuthExcelRows(@Param("deptName") String deptName);
}
```

### 9-2. `resources/mapper/B002AuthMapper.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="com.company.reactbeginner.repository.mybatis.B002AuthMapper">

    <select id="findAuthExcelRows" resultType="com.company.reactbeginner.dto.B002AuthExcelDto">
        SELECT a.AUTH_SEQ,
               a.EMP_NAME,
               a.EMP_NO,
               a.DEPT_NAME,
               a.AUTH_NAME,
               a.AUTH_GRANT,
               a.USE_YN,
               a.DETAIL_ID,
               b.DETAIL_NM,
               b.DETAIL_AUTH,
               b.DETAIL_USE_YN
          FROM TB_B002_AUTH_EXCEL a
         INNER JOIN TB_B002_AUTH_EXCEL_DETAIL b
            ON a.DETAIL_ID = b.DETAIL_ID
        <if test="deptName != null and deptName != ''">
         WHERE a.DEPT_NAME = #{deptName}
        </if>
         ORDER BY a.EMP_NO, a.AUTH_NAME, a.AUTH_SEQ
    </select>

</mapper>
```

`#{deptName}`은 PreparedStatement 바인딩입니다. 문자열을 SQL에 이어 붙이지 않습니다.  
`resultType` DTO의 `empName` ↔ 컬럼 `EMP_NAME`은 `map-underscore-to-camel-case`로 맞춰집니다.

`namespace` + `id`가 자바 인터페이스의 FQCN + 메서드명과 같아야 합니다.

## 11. Service — 두 저장소를 함께 쓰기

```java
package com.company.reactbeginner.service;

import com.company.reactbeginner.domain.AuthExcelDetail;
import com.company.reactbeginner.dto.B002AuthExcelDto;
import com.company.reactbeginner.dto.B002DetailSyncRequest;
import com.company.reactbeginner.dto.DetailListItemDto;
import com.company.reactbeginner.repository.jpa.AuthExcelDetailRepository;
import com.company.reactbeginner.repository.mybatis.B002AuthMapper;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.HashSet;
import java.util.List;
import java.util.Set;

@Service
public class B002AuthService {

    private final B002AuthMapper b002AuthMapper;
    private final AuthExcelDetailRepository detailRepository;

    public B002AuthService(B002AuthMapper b002AuthMapper,
                           AuthExcelDetailRepository detailRepository) {
        this.b002AuthMapper = b002AuthMapper;
        this.detailRepository = detailRepository;
    }

    /** 복잡한 그리드 조회 — MyBatis JOIN */
    @Transactional(readOnly = true)
    public List<B002AuthExcelDto> search(String departmentCode) {
        return b002AuthMapper.findAuthExcelRows(departmentCode);
    }

    /** 단순 등록·삭제 — JPA */
    @Transactional
    public void syncRowDetails(B002DetailSyncRequest request) {
        String detailId = request.parentDetailId();
        Set<String> selected = new HashSet<>();
        if (request.selectedDetails() != null) {
            for (DetailListItemDto item : request.selectedDetails()) {
                selected.add(item.detailAuth());
            }
        }

        List<AuthExcelDetail> current = detailRepository.findByDetailId(detailId);

        for (AuthExcelDetail row : current) {
            if (!selected.contains(row.getDetailAuth())) {
                detailRepository.delete(row);
            }
        }

        Set<String> currentAuths = new HashSet<>();
        current.forEach(row -> currentAuths.add(row.getDetailAuth()));

        for (DetailListItemDto item : request.selectedDetails()) {
            if (!currentAuths.contains(item.detailAuth())) {
                detailRepository.save(new AuthExcelDetail(
                        detailId, item.detailNm(), item.detailAuth(), "Y"
                ));
            }
        }
    }
}
```

- **search**: JOIN이 있으므로 MyBatis
- **syncRowDetails**: 한 테이블 INSERT/DELETE이므로 JPA + `@Transactional`

같은 메서드에서 같은 테이블을 MyBatis로도 지우면 JPA 1차 캐시와 어긋날 수 있습니다. 쓰기는 JPA만 사용합니다.

## 12. Controller 예

```java
@RestController
@RequestMapping("/api/b002")
public class B002Controller {

    private final B002AuthService b002AuthService;

    public B002Controller(B002AuthService b002AuthService) {
        this.b002AuthService = b002AuthService;
    }

    @GetMapping("/search")
    public Map<String, Object> search(@RequestParam(required = false) String departmentCode) {
        List<B002AuthExcelDto> rows = b002AuthService.search(departmentCode);
        return Map.of(
                "success", true,
                "data", rows,
                "totalCount", rows.size()
        );
    }

    @PostMapping("/details/sync")
    public Map<String, Object> sync(@RequestBody B002DetailSyncRequest request) {
        b002AuthService.syncRowDetails(request);
        return Map.of("success", true);
    }
}
```

`Map.of`는 Java 9+ 불변 Map입니다. `null` 값은 넣을 수 없으니, null이 필요하면 `HashMap`을 씁니다.

## 15. 선택 체크리스트

| 할 일 | 위치 |
|-------|------|
| 한 행 조회·저장·삭제 | `repository.jpa` + Entity |
| 조건 몇 개의 목록 | QueryDSL `*QueryRepository` |
| JOIN / DISTINCT / 긴 SELECT | `resources/mapper/*.xml` |
| 트랜잭션 경계 | Service `@Transactional` |
| JSON 키 | DTO / record (Entity 직접 반환 금지) |
| Java 버전 | `build.gradle` toolchain 21 |
| Q클래스가 안 생김 | `:jakarta` classifier, `compileJava` |
