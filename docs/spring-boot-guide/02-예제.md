# Spring Boot 가이드 — 예제

설명에서 본 주제를 이 프로젝트 코드와 짧은 추가 예제로 확인합니다.  
파일 경로는 `backend/` 기준입니다.

---

## 1. Spring Boot — `pom.xml` parent

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>2.7.18</version>
    <relativePath/>
</parent>

<properties>
    <java.version>1.8</java.version>
</properties>
```

parent 버전이 Boot 버전입니다.  
Java 8을 쓰려면 `java.version`을 `1.8`로 맞춥니다.

## 2. 패키지 배치 예

실제 디렉터리:

```
com.company.reactbeginner
├── ReactBeginnerApplication.java
├── config.WebConfig
├── controller.GridController
├── controller.B002Controller
├── service.GridMockService
├── service.B002AuthService
├── repository.B002AuthRepository
└── dto.CodeNameDto, GridRowDto, ...
```

새 API를 추가할 때의 최소 파일:

1. `dto` — 응답/요청 클래스
2. `service` — 비즈니스 메서드
3. `controller` — URL 매핑
4. (DB가 필요하면) `repository` — SQL

## 4. 진입점 예

파일: `src/main/java/com/company/reactbeginner/ReactBeginnerApplication.java`

```java
package com.company.reactbeginner;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class ReactBeginnerApplication {

    public static void main(String[] args) {
        SpringApplication.run(ReactBeginnerApplication.class, args);
    }
}
```

실행:

```bash
cd backend
./mvnw spring-boot:run          # Linux / macOS
mvnw.cmd spring-boot:run        # Windows
```

Windows에서는 `run-backend.bat`을 더블클릭해도 됩니다.

콘솔에 `Tomcat started on port(s): 8080`이 보이면 성공입니다.

## 6. 생성자 주입 예

Controller가 Service를 받는 방식 (`GridController`):

```java
@RestController
@RequestMapping("/api/grid")
public class GridController {

    private final GridMockService gridMockService;

    public GridController(GridMockService gridMockService) {
        this.gridMockService = gridMockService;
    }
}
```

Repository가 `JdbcTemplate`을 받는 방식 (`B002AuthRepository`):

```java
@Repository
public class B002AuthRepository {

    private final JdbcTemplate jdbcTemplate;

    public B002AuthRepository(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }
}
```

필드에 `@Autowired`를 붙이지 않아도, 생성자가 하나면 Spring이 주입합니다.

## 8. `@RequestParam` / `@RequestBody` 예

### 8-1. 선택 파라미터와 CSV 파싱 (B001 검색)

```java
@GetMapping("/search")
public Map<String, Object> search(@RequestParam String week,
                                  @RequestParam(required = false) String departmentCode,
                                  @RequestParam(required = false) String sectionCode,
                                  @RequestParam(required = false) String categoryCodes,
                                  @RequestParam(required = false) String statusCode,
                                  @RequestParam(required = false) String typeCodes) {
    List<String> categoryCodeList = parseCsv(categoryCodes);
    List<String> typeCodeList = parseCsv(typeCodes);

    List<GridRowDto> rows = gridMockService.searchGrid(
            week, departmentCode, sectionCode, categoryCodeList, statusCode, typeCodeList
    );

    Map<String, Object> result = new HashMap<>();
    result.put("success", true);
    result.put("data", rows);
    result.put("totalCount", rows.size());
    return result;
}

private List<String> parseCsv(String value) {
    if (value == null || value.trim().isEmpty()) {
        return Collections.emptyList();
    }
    return Arrays.stream(value.split(","))
            .map(String::trim)
            .filter(s -> !s.isEmpty())
            .collect(Collectors.toList());
}
```

호출 예:

```text
GET /api/grid/search?week=202627&departmentCode=D02&categoryCodes=C01,C02&typeCodes=T01
```

`week`를 빼면 400입니다. `departmentCode`를 빼면 전체 부서로 조회합니다.

## 9. 응답 래핑 예

옵션 API와 검색 API의 차이는 `totalCount` 유무입니다.

```java
// 옵션
result.put("success", true);
result.put("data", list);

// 검색
result.put("success", true);
result.put("data", rows);
result.put("totalCount", rows.size());
```

프론트는 보통 `response.data.data`처럼 axios 응답의 `data`와 서버 JSON의 `data`를 한 번씩 꺼냅니다.

## 10. Service 예 — 목 데이터 필터

파일: `service/GridMockService.java`

```java
@Service
public class GridMockService {

    public List<CodeNameDto> getDepartments(String week) {
        if ("202627".equals(week)) {
            return Arrays.asList(
                    new CodeNameDto("D01", "영업부"),
                    new CodeNameDto("D02", "개발부"),
                    new CodeNameDto("D03", "인사부")
            );
        }
        return Arrays.asList(
                new CodeNameDto("D01", "영업부"),
                new CodeNameDto("D02", "개발부")
        );
    }

    public List<CodeNameDto> getSections(String week, String departmentCode) {
        List<CodeNameDto> sections = new ArrayList<>();
        sections.add(new CodeNameDto("ALL", "전체"));

        if ("D01".equals(departmentCode)) {
            sections.add(new CodeNameDto("S01", "국내영업팀"));
            sections.add(new CodeNameDto("S02", "해외영업팀"));
        } else if ("D02".equals(departmentCode)) {
            sections.add(new CodeNameDto("S03", "프론트엔드팀"));
            sections.add(new CodeNameDto("S04", "백엔드팀"));
        }
        return sections;
    }
}
```

DB 없이 화면 흐름을 만들 때 이 패턴을 씁니다.  
조건 분기는 Service에 두고, Controller는 결과만 감쌉니다.

팀 목록의 첫 항목이 항상 `"ALL" / "전체"`인 것은 B001 화면 요구사항입니다.

## 11. DTO 예

옵션용 최소 DTO (`dto/CodeNameDto.java`):

```java
public class CodeNameDto {

    private String code;
    private String name;

    public CodeNameDto() {
    }

    public CodeNameDto(String code, String name) {
        this.code = code;
        this.name = name;
    }

    public String getCode() { return code; }
    public void setCode(String code) { this.code = code; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}
```

Jackson은 `getCode()` → JSON 키 `"code"`로 직렬화합니다.  
기본 생성자(`CodeNameDto()`)는 JSON을 객체로 읽을 때(역직렬화) 필요합니다.

## 12. JdbcTemplate 예

파일: `repository/B002AuthRepository.java`

### 12-1. SELECT + RowMapper

```java
private static final RowMapper<B002AuthExcelDto> ROW_MAPPER = new RowMapper<B002AuthExcelDto>() {
    @Override
    public B002AuthExcelDto mapRow(ResultSet rs, int rowNum) throws SQLException {
        B002AuthExcelDto dto = new B002AuthExcelDto();
        dto.setName(rs.getString("EMP_NAME"));
        dto.setEmpNo(rs.getString("EMP_NO"));
        dto.setDept(rs.getString("DEPT_NAME"));
        dto.setAuthName(rs.getString("AUTH_NAME"));
        dto.setDetailId(rs.getString("DETAIL_ID"));
        return dto;
    }
};
```

컬럼명(`EMP_NAME`)과 DTO 필드(`name`)는 달라도 됩니다.  
매핑은 `mapRow`에서 직접 연결합니다.

### 12-2. 동적 WHERE

```java
public List<B002AuthExcelDto> findAuthExcelRows(String deptName) {
    StringBuilder sql = new StringBuilder();
    sql.append("SELECT a.EMP_NAME, a.EMP_NO, a.DEPT_NAME, a.AUTH_NAME, ");
    sql.append("       a.DETAIL_ID, b.DETAIL_NM, b.DETAIL_AUTH ");
    sql.append("FROM TB_B002_AUTH_EXCEL a ");
    sql.append("INNER JOIN TB_B002_AUTH_EXCEL_DETAIL b ON a.DETAIL_ID = b.DETAIL_ID ");

    List<Object> params = new ArrayList<Object>();
    if (deptName != null && !deptName.trim().isEmpty()) {
        sql.append("WHERE a.DEPT_NAME = ? ");
        params.add(deptName.trim());
    }

    sql.append("ORDER BY a.EMP_NO, a.AUTH_NAME, a.AUTH_SEQ");
    return jdbcTemplate.query(sql.toString(), params.toArray(), ROW_MAPPER);
}
```

문자열을 SQL에 이어 붙이지 말고 항상 `?` + `params`를 씁니다.

### 12-3. 한 컬럼만 조회 (람다 RowMapper)

```java
public List<String> findDistinctDepartments() {
    return jdbcTemplate.query(
            "SELECT DISTINCT DEPT_NAME FROM TB_B002_AUTH_EXCEL ORDER BY DEPT_NAME",
            (rs, rowNum) -> rs.getString("DEPT_NAME")
    );
}
```

Java 8 람다로 `RowMapper`를 짧게 쓸 수 있습니다.

### 12-4. INSERT / DELETE

```java
public void insertDetail(String detailId, String detailNm, String detailAuth, String detailUseYn) {
    jdbcTemplate.update(
            "INSERT INTO TB_B002_AUTH_EXCEL_DETAIL (DETAIL_ID, DETAIL_NM, DETAIL_AUTH, DETAIL_USE_YN) "
                    + "VALUES (?, ?, ?, ?)",
            detailId, detailNm, detailAuth, detailUseYn
    );
}

public void deleteDetailByIdAndAuth(String detailId, String detailAuth) {
    jdbcTemplate.update(
            "DELETE FROM TB_B002_AUTH_EXCEL_DETAIL WHERE DETAIL_ID = ? AND DETAIL_AUTH = ?",
            detailId, detailAuth
    );
}
```

`update`의 반환값은 영향받은 행 수입니다. 이 프로젝트는 값을 쓰지 않고 호출만 합니다.

## 13. 트랜잭션 예

파일: `service/B002AuthService.java`

```java
@Service
public class B002AuthService {

    private final B002AuthRepository b002AuthRepository;

    public B002AuthService(B002AuthRepository b002AuthRepository) {
        this.b002AuthRepository = b002AuthRepository;
    }

    @Transactional
    public List<B002DetailItemDto> syncRowDetails(B002DetailSyncRequest request) {
        // 1) 현재 DB에 있는 세부권한
        List<String> currentAuths = b002AuthRepository.findAssignedDetailAuths(empNo, authName);

        // 2) 선택 목록에 없는 것은 DELETE
        for (String detailAuth : currentSet) {
            if (!selectedAuths.contains(detailAuth)) {
                b002AuthRepository.deleteDetailByIdAndAuth(detailId, detailAuth);
            }
        }

        // 3) 새로 고른 것은 INSERT
        b002AuthRepository.insertDetail(detailId, detailNm, detailAuth, "Y");

        return /* 최종 목록 */;
    }
}
```

`insertDetail` 도중 예외가 나면 앞에서 실행한 `deleteDetailByIdAndAuth`도 롤백됩니다.  
`@Transactional`이 없으면 DELETE만 커밋된 채 남을 수 있습니다.

## 14. CORS 예

파일: `config/WebConfig.java`

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("http://localhost:5173", "http://127.0.0.1:5173")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*");
    }
}
```

프론트를 다른 포트(예: 3000)에서 띄우면 여기 origin을 추가해야 합니다.  
`localhost`와 `127.0.0.1`은 브라우저가 다른 출처로 보므로 둘 다 넣습니다.
